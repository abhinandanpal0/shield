JSON API

Scan text from scripts, pipelines or other apps. Requests are limited to {{ '{:,}'.format(max_chars) }} characters and {{ limit }} requests per minute for each IP address.

Scan text

POST /api/v1/scan with a JSON body.

curl -X POST {{ request.host_url }}api/v1/scan \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Mail meera@example.com or call 98765 43210",
    "style": "label",
    "detectors": ["email", "phone"],
    "include_values": false
  }'

Request fields

text
Required string to scan.
style
Optional. mask (default), label or block.
detectors
Optional list of detector ids. Leave it out to use all of them.
include_values
Optional boolean. When true, each finding includes the original value. Defaults to false.

Response

{
  "summary": {
    "total": 2,
    "by_severity": {"high": 0, "medium": 2, "low": 0},
    "by_type": [{"label": "Email address", "severity": "medium", "count": 1}, ...],
    "risk": "medium"
  },
  "findings": [
    {"type": "email", "label": "Email address", "severity": "medium",
     "confidence": "high", "masked": "m***@example.com",
     "start": 5, "end": 21, "line": 1, "column": 6}
  ],
  "redacted_text": "Mail [EMAIL] or call [PHONE]"
}

Other endpoints

GET /api/v1/detectors
Lists detector ids, severity, validation rules and examples.
GET /healthz
Returns {"status": "ok"} for uptime checks.

Errors

Errors return JSON with error and message. Status codes: 400 for invalid input, 413 for text over the limit, 429 when rate limited (check the Retry-After header).
