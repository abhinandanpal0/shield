Privacy and limits

A tool that handles personal data should be clear about what it does with it.

What PII Shield stores

Nothing you submit is written to a database or to disk. Text and uploaded files are held in memory while the scan runs and are discarded when the response is sent. Server logs record only the number of characters scanned and findings returned, never the content.

The page sets one cookie, a random security token that protects the form against cross-site requests. It holds no personal information.

Protections built in

  • Strict Content Security Policy, with no third-party scripts
  • CSRF protection on the form and request limits per IP address
  • Size limits: {{ '{:,}'.format(max_chars) }} characters of text, 256 KB per uploaded file
  • Responses to scans are marked no-store so browsers and proxies do not cache them
  • Fonts load from Google Fonts. Self-host them if that matters for your deployment

Limits you should know about

  • Detection is pattern-based and will miss some data and flag some harmless numbers.
  • Aadhaar checks confirm that a number is structurally valid, not that it belongs to a real person.
  • Names and addresses are not detected.
  • If you run this over plain HTTP, anything you paste can be read on the network. Use HTTPS.

Use fake data when you try the tool, and do not paste anything you are not allowed to process.
